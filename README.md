🏗️ Projet

ConstrucBudget

🎯 Description

ConstrucBudget est un site qui aide à estimer le budget de construction d’une maison et à mieux gérer les dépenses.

❗ Problème

Dans la construction :

les budgets sont mal estimés
les coûts augmentent souvent
les chantiers sont parfois arrêtés
💡 Solution

Le site permet de :

estimer le coût d’une maison
calculer les dépenses
suivre le budget
🧱 Fonctionnalités
estimation du budget
choix du type de maison
calcul automatique
suivi des dépenses
🛠️ Technologies
HTML
CSS
JavaScript
🎯 Objectif

Aider les gens à mieux organiser leur budget de construction.
